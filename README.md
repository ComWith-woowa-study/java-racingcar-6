## 기능 목록

입력 :
- [x] 자동차에 이름을 부여한다.
  - [x] 이름은 5자 이하만 가능하다.
- [x] 몇 번의 이동을 할 것인지 정한다.
  - [x] 양의 정수값만 입력 받는다.

출력 :
- [x] 한 번 이동을 할 때마다 각 자동차 이름과 전진 거리를 같이 출력한다.
- [x] 게임을 완료한 후 우승자를 알려준다.
  - [x] 우승자는 한 명 이상일 수 있다.
  - [x] 우승자가 여러 명일 경우 쉼표를 이용해 구분한다.

기능 : 
- [x] 주어진 이동 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다
- [x] 전진 조건은 0~9 사이 무작위 값을 구한 후 그 값이 4 이상일 경우다.
